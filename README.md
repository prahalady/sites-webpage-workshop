# Sites 웹페이지 제작 실습

업무에 활용하고, 나의 역량을 보여 주는 웹페이지를 만드는 수업용 예시 모음입니다.

## 들어 있는 내용

- 전공 포트폴리오 6개
- 업무·행정 4개
- 교육·캠퍼스 3개
- 창업·지역 2개
- 각 예시의 추가 요청 2개: 총 30개

## 사용 방법

1. 저장소의 **Code → Download ZIP**을 눌러 파일을 내려받고 압축을 풉니다.
2. `index.html`을 Chrome 또는 Edge에서 엽니다.
3. 분야나 검색으로 원하는 상황을 찾고 **예시 보기**를 누릅니다.
4. 방문자·핵심 메시지·바꿔 쓸 부분을 확인하고 프롬프트를 수정합니다.
5. **프롬프트 전체 복사**를 눌러 Sites에 붙여 넣습니다.
6. 첫 웹페이지가 나오면 같은 Sites 대화에 **추가 요청**을 이어서 입력합니다.

복사 권한이 없는 환경에서는 선택된 내용을 Ctrl+C 또는 ⌘C로 직접 복사할 수 있습니다. 수정한 내용은 현재 페이지에서만 유지되고 새로고침하면 초기화됩니다.

## 파일

- `index.html`: CSS·JavaScript·전체 예시가 포함된 독립 실행 HTML. 외부 라이브러리나 서버 설치 없이 사용할 수 있습니다.

예시는 가상 자료와 작성할 자리를 사용합니다. 실제 작품·성과·연락처로 바꿀 때는 내용을 확인해 주세요.
